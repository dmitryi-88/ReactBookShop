# 📚 React Book Shop

Интернет-магазин книг, разработанный на **React**.
Проект создан в учебных целях для практики работы с React, состоянием приложения, API, маршрутизацией и современным подходом к организации компонентов.

##  Возможности

*  Просмотр каталога книг
*  Поиск книг
*  Фильтрация книг по автору
*  Просмотр подробной информации о книге
*  Добавление книг в корзину с использованием localeStorage
*  Изменение количества товаров в корзине
*  Оформление заказа, с обновленем остатков товара
*  Удаление товаров из корзины
*  Просмотр списка заказов
*  Переключение светлой и тёмной темы
*  Сохранение темы в `localStorage`
*  Toast-уведомления
*  Загрузка данных через TanStack Query
*  Состояния загрузки и обработки ошибок
*  Адаптивная вёрстка

##  Технологии

### Frontend

* React
* React Router
* JavaScript
* SCSS / CSS Modules
* Vite

### Работа с данными

* TanStack Query (React Query)
* JSON Server
* Fetch API

### Дополнительно

* React Context API
* React Hooks
* LocalStorage

* CSS Variables


##  Запуск проекта

Клонируйте репозиторий:

```bash
git clone <https://github.com/dmitryi-88/ReactBookShop>
```

Перейдите в папку проекта:

```bash
cd ReactBookShop
```

Установите зависимости:

```bash
npm install
```

Запустите JSON Server:

```bash
npm run server
```

Запустите приложение:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```

##  API

Для хранения данных используется **JSON Server**.

По умолчанию API работает на:

```text
http://localhost:3001
```

Основные данные каталога находятся в:

```text
db.json
```

Пример структуры книги:

```json
{
    "id": 1,
    "title": "Название книги",
    "author": "Автор",
    "price": 195,
    "stock": 5,
    "image": "image-url",
    "description": "..."
}
```

##  Темизация

В проекте реализована светлая и тёмная тема.

Для управления темой используется:

* `ThemeContext`
* `ThemeProvider`
* CSS Variables
* `localStorage`

Цвета интерфейса задаются через CSS-переменные:

```scss
:root {
    --color: #fff;
    --color: #000
}
```

Тема переключается без необходимости дублировать стили каждого компонента.

##  TanStack Query

Получение данных каталога реализовано с помощью **TanStack Query**.

Это позволяет:

* управлять состоянием загрузки;
* обрабатывать ошибки;
* кэшировать полученные данные;
* повторять запросы;
* вручную обновлять данные.


##  Корзина

Корзина позволяет:

* добавлять книги;
* увеличивать и уменьшать количество;
* удалять товары;
* рассчитывать итоговую стоимость;
* отображать состояние пустой корзины.

Для пользовательских уведомлений используется Toast-компонент.

##  Адаптивность

Интерфейс адаптирован под различные размеры экрана с использованием SCSS и media queries.

##  Цель проекта

Основная цель проекта — практическое применение React и закрепление следующих навыков:

* создание компонентов;
* работа с `useState`, `useEffect`, `useContext` и другими Hooks;
* управление глобальным состоянием через Context;
* работа с REST API;
* использование TanStack Query;
* маршрутизация;
* работа с вложенными структурами данных;
* организация структуры React-приложения;
* SCSS и CSS Modules;
* создание переиспользуемых компонентов;
* обработка состояний `loading`, `error`, `empty`;
* работа с `localStorage`.
